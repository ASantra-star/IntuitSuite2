FieldPro, what happened

Diagnosed by Developer Assistant
  1. 11:41 PMIntuit rotated the OAuth refresh token (normal behavior).
  2. 11:41 PMConnector v4.12 saved the new token to cache, not to the vault. Cache cleared on restart.
  3. 11:42 PMNext request returned 401 invalid_grant. Sync paused automatically.
  4. Since214 job.completed events held in the queue. Nothing lost, nothing double-posted.

Suggested fix

Reconnect FieldPro with fresh consent, then replay the 214 held events. Replay runs in batches of 30 so it stays under this company's 500 requests per minute. Writes are free, so replay doesn't use metered read credits.

What it does, in plain words

Renee will see this exact text when she approves

Every morning at 6:00, check each entity's gross margin against forecast. If one drifts more than 1.5 points, say which jobs or accounts explain it and whether the cause looks like a data problem or a business problem. Draft a note for Renee. Never post anything.

agent: margin-watch
runs: daily at 6:00 AM
triggers: [schedule, fieldpro.job.completed]
reads: [ies.gl, ies.jobs, fieldpro.jobs]
sync: poll_all_entities_daily
can_write: drafts_only
approval: role:controller
escalate:
  - { when: policy_missing, to: intuit_expert }
  - { when: sync_gap, to: "#integrations" }
